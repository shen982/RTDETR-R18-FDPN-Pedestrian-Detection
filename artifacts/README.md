# Frozen runtime

`public_runtime_code_v5.zip` contains the complete attributed runtime source, required dependency overlays, exact model YAMLs, new reproduction workers and a source/data hash manifest. It has no dataset images or weights; the reproduction program combines the separate verified assets.

The same ZIP is supplied with v1.1.0. Its SHA-256 is in [ASSETS.json](../reproduction/ASSETS.json). v4 remains for historical v1.0.0 provenance; use v5 for complete reproduction.

The native dependency overlay requires Python 3.11 on Linux x86_64. See [installation](../docs/REPRODUCTION.md) and [attribution](../LICENSES.md).
